# O shell (sagsh): a ajuda. Descrição curta: até 17 letras.
lista arquivos = list files
Mostra os arquivos e pastas (pastas terminam com /). = Shows the files and folders (folders end with /).
entra numa pasta = change folder
Muda a pasta atual. "cd .." volta uma; "cd" sozinho vai para a raiz. = Changes the current folder. "cd .." goes up one; "cd" alone goes to the root.
mostra a pasta = show folder
Mostra em que pasta você está. = Shows which folder you are in.
mostra um arquivo = show a file
Mostra o conteúdo dos arquivos. Sem arquivo, mostra o que chegar pela entrada. = Shows the contents of files. With no file, shows what comes from the input.
escreve um texto = print a text
Escreve o texto. Com "> arquivo" grava num arquivo. = Prints the text. With "> file" it writes to a file.
copia arquivo = copy file
Copia um arquivo. Se o destino for uma pasta, copia para dentro dela. = Copies a file. If the destination is a folder, copies into it.
move ou renomeia = move or rename
Move ou renomeia um arquivo ou pasta. = Moves or renames a file or folder.
apaga arquivo = delete file
Apaga arquivos (pastas: use rmdir). = Deletes files (folders: use rmdir).
cria pasta = make folder
Cria uma pasta nova. = Creates a new folder.
apaga pasta vazia = remove empty dir
Remove uma pasta, se estiver vazia. = Removes a folder, if it is empty.
conta linhas = count lines
Conta linhas, palavras e letras de um arquivo ou da entrada (ex.: ls bin | conta). = Counts lines, words and letters of a file or of the input (e.g. ls bin | wc).
lista processos = list processes
Mostra os processos em execução: PID, pai, estado, memória e tempo de CPU. = Shows the running processes: PID, parent, state, memory and CPU time.
processos ao vivo = live processes
Mostra os processos, a memória e a %CPU de cada um, atualizando a cada segundo. q sai. = Shows the processes, memory and %CPU of each one, updating every second. q quits.
procura texto = search text
Mostra as linhas que contêm o texto (ex.: ls bin | grep a). -i ignora maiúsculas, -n numera, -v inverte, -c conta. = Shows the lines that contain the text (e.g. ls bin | grep a). -i ignores case, -n numbers, -v inverts, -c counts.
compacta (.gz) = compress (.gz)
Compacta cada arquivo em arquivo.gz (e apaga o original; -k guarda). -d descompacta, -c manda para a saída, -l lista, -f substitui. = Compresses each file into file.gz (and deletes the original; -k keeps it). -d decompresses, -c writes to the output, -l lists, -f replaces.
descompacta .gz = decompress .gz
Descompacta arquivos .gz (e .tgz, que vira .tar). Não substitui um arquivo que já existe sem -f. = Decompresses .gz files (and .tgz, which becomes .tar). Does not replace an existing file without -f.
pacotes .tar = .tar packages
c cria o pacote, x extrai, t lista; v mostra os nomes, z compacta (.tar.gz), o substitui o que já existe. Nomes com ".." são recusados. = c creates the package, x extracts, t lists; v shows the names, z compresses (.tar.gz), o replaces what already exists. Names with ".." are refused.
cria um .zip = create a .zip
Cria um pacote .zip; as pastas entram com tudo dentro. -0 só guarda, -9 compacta mais. = Creates a .zip package; folders go in with everything inside. -0 only stores, -9 compresses more.
abre um .zip = open a .zip
Extrai um .zip na pasta atual (ou na do -d). -l lista, -t confere, -o substitui o que já existe. Nomes com ".." são recusados. = Extracts a .zip into the current folder (or the -d one). -l lists, -t checks, -o replaces what already exists. Names with ".." are refused.
começo do texto = start of text
Mostra as primeiras linhas (10, ou N com -n) de arquivos ou da entrada (ex.: ls bin | head -3). -c conta bytes. = Shows the first lines (10, or N with -n) of files or of the input (e.g. ls bin | head -3). -c counts bytes.
fim do texto = end of text
Mostra as últimas linhas (10, ou N com -n); com +N, da linha N em diante. -f continua mostrando o que for acrescentado. = Shows the last lines (10, or N with -n); with +N, from line N on. -f keeps showing what gets appended.
ordena linhas = sort lines
Ordena as linhas. -r inverte, -n compara números, -u tira repetidas, -f ignora maiúsculas, -k ordena pelo campo N, -t escolhe o separador. = Sorts the lines. -r reverses, -n compares numbers, -u removes repeats, -f ignores case, -k sorts by field N, -t picks the separator.
junta repetidas = merge repeats
Junta linhas repetidas seguidas (use depois do sort). -c conta, -d só as repetidas, -u só as únicas, -i ignora maiúsculas. = Merges repeated adjacent lines (use after sort). -c counts, -d only repeated, -u only unique, -i ignores case.
corta colunas = cut columns
Mostra só alguns campos (-f, separados por -d; o padrão é Tab) ou colunas (-c) de cada linha. LISTA: 2  1,3  2-4  3-. = Shows only some fields (-f, separated by -d; Tab by default) or columns (-c) of each line. LIST: 2  1,3  2-4  3-.
troca letras = translate chars
Troca as letras do conjunto 1 pelas do 2 (ex.: tr a-z A-Z ou tr [:lower:] [:upper:]). -d apaga, -s junta repetidas, -c usa o complemento. = Replaces the letters of set 1 with those of set 2 (e.g. tr a-z A-Z or tr [:lower:] [:upper:]). -d deletes, -s squeezes repeats, -c uses the complement.
conta números = count numbers
Escreve uma sequência de números, um por linha (ex.: seq 5, seq 10 -2 0, seq 0 0.5 2). -w iguala a largura, -s troca o separador. = Prints a sequence of numbers, one per line (e.g. seq 5, seq 10 -2 0, seq 0 0.5 2). -w equalizes the width, -s changes the separator.
inverte as letras = reverse letters
Escreve cada linha de trás para a frente (sagui vira iugas). = Prints each line backwards (sagui becomes iugas).
inverte a ordem = reverse order
Escreve as linhas na ordem inversa, da última para a primeira. = Prints the lines in reverse order, from the last to the first.
numera linhas = number lines
Numera as linhas com texto (com -b a, todas). -w largura, -s separador, -v primeiro número, -i incremento. = Numbers the lines with text (with -b a, all of them). -w width, -s separator, -v first number, -i increment.
compara arquivos = compare files
Mostra as linhas que mudaram de um arquivo para o outro (< saiu, > entrou). -u formato unificado, -q só diz se mudou, -i ignora maiúsculas, -b espaços. = Shows the lines that changed from one file to the other (< removed, > added). -u unified format, -q only says if it changed, -i ignores case, -b spaces.
acha arquivos = find files
Procura arquivos e pastas, descendo pelas subpastas (ex.: find /usb -name "*.txt"). ! inverte a condição seguinte. = Searches files and folders, going down into subfolders (e.g. find /usb -name "*.txt"). ! inverts the next condition.
edita texto = edit text
Edita o texto linha a linha: s/velho/novo/g troca, 3d apaga a linha 3, /^#/d apaga as que começam com #, -n 2,4p mostra só as linhas 2 a 4. = Edits the text line by line: s/old/new/g replaces, 3d deletes line 3, /^#/d deletes the ones starting with #, -n 2,4p shows only lines 2 to 4.
árvore de pastas = folder tree
Desenha as pastas e os arquivos como uma árvore. -d só pastas, -L N desce até N níveis, -a mostra os escondidos. = Draws the folders and files as a tree. -d only folders, -L N goes down N levels, -a shows hidden ones.
calendário = calendar
Mostra o calendário do mês de hoje, de um mês (cal 2 2028) ou do ano inteiro (cal 2027). = Shows the calendar of the current month, of a month (cal 2 2028) or of a whole year (cal 2027).
calcula contas = calculator
Calculadora com números de muitos dígitos: echo "2^100" | bc, echo "scale=2; 10/3" | bc. Tem + - * / % ^, sqrt(), variáveis e scale (casas). = Calculator with many-digit numbers: echo "2^100" | bc, echo "scale=2; 10/3" | bc. Has + - * / % ^, sqrt(), variables and scale (decimals).
calcula expressão = evaluate expr
Calcula uma expressão com cada parte separada: expr 3 + 4, expr 7 / 2, expr abc \= abc, expr length sagui. Código 1 se der 0 ou vazio. = Evaluates an expression with each part separated: expr 3 + 4, expr 7 / 2, expr abc \= abc, expr length sagui. Exit code 1 if the result is 0 or empty.
codifica base64 = base64 encode
Codifica um arquivo em letras e números (RFC 4648); -d decodifica de volta, -w muda a largura das linhas (0 \= uma só). = Encodes a file as letters and digits (RFC 4648); -d decodes it back, -w changes the line width (0 \= a single line).
resumo MD5 = MD5 digest
Calcula o resumo MD5 (RFC 1321) de arquivos, para conferir cópias; -c confere uma lista "resumo  nome". = Computes the MD5 digest (RFC 1321) of files, to check copies; -c checks a "digest  name" list.
bytes em números = bytes as numbers
Mostra os bytes de um arquivo como números: octal (padrão), -t x1 hexadecimal, -c letras, -t d2 decimal com sinal... = Shows the bytes of a file as numbers: octal (default), -t x1 hexadecimal, -c letters, -t d2 signed decimal...
bytes em hexa = bytes in hex
Mostra os bytes em hexadecimal ao lado das letras; -p só o hexadecimal, -r faz o caminho de volta (do hexadecimal para os bytes). = Shows the bytes in hexadecimal next to the letters; -p only the hexadecimal, -r goes back (from hexadecimal to bytes).

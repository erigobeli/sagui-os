# H100. Boot em modo longo

**Fase:** 1

## Objetivo

O estágio 2 confere o CPUID (bit LM), monta tabelas de página de 4 níveis com a identidade dos primeiros GB, liga PAE, EFER.LME e a paginação, salta para um segmento de 64 bits e entra no kernel ELF64.

## Critério de aceite

no QEMU e no VirtualBox, o kernel de 64 bits escreve na tela e na serial; numa CPU sem 64 bits, uma mensagem clara.
